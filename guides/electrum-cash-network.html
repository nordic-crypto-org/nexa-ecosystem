Using @electrum-cash/network with Nexa

@electrum-cash/network is a generic Electrum-protocol client for JavaScript. Version 4.4.8 works unchanged against Nexa's Rostrum servers, including the token.* calls.

  • Passing only a hostname uses the BCH default port (50004) and fails. Create the socket yourself with @electrum-cash/web-socket on port 20004.
  • Use useBigInt: true so 64-bit token amounts are not rounded.
  • Endpoints on electrum.nexa.org: WSS 20004, WS 20003, TLS 20002, TCP 20001 (TCP/TLS via @electrum-cash/tcp-socket).
npm install @electrum-cash/network @electrum-cash/web-socket
import { ElectrumClient } from '@electrum-cash/network';
import { ElectrumWebSocket } from '@electrum-cash/web-socket';

const NEXA_GENESIS = 'edc7144fe1ba4edd0edf35d7eea90f6cb1dba42314aa85da8207e97c5339c801';
const socket = new ElectrumWebSocket('electrum.nexa.org', { port: 20004 });
const client = new ElectrumClient('my-app', '1.4', socket, { useBigInt: true });
await client.connect();

const features = await client.request('server.features');
console.log('Nexa mainnet:', features.genesis_hash === NEXA_GENESIS);
console.log(await client.request('blockchain.address.get_balance', 'nexa:nqcqq9zxrtf9pqwtqyvaqdpctlc4fjxn444a6as5lun7vu0aw04cgk2k872qccv3lzcgnct9q06qxysqdpqxkpwy'));
console.log(await client.request('token.genesis.info', 'nexa:trm9zcajh900a02t8fmqklw99uflcvcd6antut98asxfxlq4rcqqqdw80lls5'));
await client.disconnect();

Failed calls resolve to an Error instance instead of throwing, so check result instanceof Error.
